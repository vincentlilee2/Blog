**正文：**

我把自己的个人博客开源了 🎉 一个基于 Astro 的极简博客系统，写文章 = 新建一个 Markdown 文件，保存即发布。

为什么我觉得它好用：

1️⃣ 内容即文件
每篇文章就是一个 .md 文件，用任何编辑器都能写。没有数据库、没有后台登录，Git 就是版本管理，写错了随时回滚。

2️⃣ 可以用 Obsidian 写作
如果你用 Obsidian 管理笔记，把博客文章目录软链进你的 Vault，直接在 Obsidian 里写作、打标签、双链，保存就写回文件。写作体验拉满。

3️⃣ 自带本地发布后台
不想碰命令行？内置一个本地网页后台（无鉴权、仅本机），在浏览器里新建/编辑文章、传图片、配站点信息，像用 CMS 一样。注意只在本机用，别暴露公网。

4️⃣ 构建即发布
npm run build 生成纯静态站点，部署到任意平台——nginx、GitHub Pages、Vercel、Cloudflare 都行。有 RSS、标签、归档、暗色主题、移动端适配，SEO 也做了。

5️⃣ 完全开源
MIT 协议，代码干净，README 有完整的中文文档（部署、Obsidian 接入、本地后台都有说明）。clone 下来 npm install 就能跑。

技术栈：Astro 5 + Markdown + Express（本地后台）。Node 18+ 即可。
