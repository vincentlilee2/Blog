你好，这是 **记忆花园 (MemoryGarden) Blog** 的一篇示例文章。

本仓库是一个基于 [Astro](https://astro.build) 的现代博客系统，内容为本地 Markdown 文件，构建为纯静态站点。你可以用它记录技术笔记、创作与生活。

## 这个仓库能做什么

- ⚡ Astro 静态生成，零运行时、极快加载
- 📝 Markdown 即内容：每篇文章是一个 `.md` 文件
- 🏷️ 标签系统、按月归档、RSS 订阅
- 🌗 明/暗主题切换
- 📱 响应式，移动端友好
- 🪪 自带 H5 电子名片页（`/card/`）

## 如何开始

1. 在 `src/content/blog/` 下新建 `.md` 文件
2. 写 frontmatter + 正文
3. `npm run dev` 本地预览，或 `npm run build` 构建

更多用法见仓库 README。
